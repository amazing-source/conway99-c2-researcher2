# Referee-reported wording corrections

The original reference files are copied unchanged for provenance. Read them with these explicit corrections, reported in the supplied audit transcript.

1. In PROOF_CURRENT.md, the diagonal entry of X^2+X is 8. In the parity argument it is **congruent to zero modulo 2**, not literally equal to zero. Use

       (X^2+X)_cc = 8 ≡ 0 (mod 2).

2. The classification of a 2+2 possible matching block includes **infeasible** blocks: lack of a doubly stochastic pattern gives no feasible D. It must not be silently omitted.

3. Distinguish the unconditional equivalence for involutions with exactly one fixed vertex from the full C2 equivalence, whose graph-to-N direction additionally uses F0.

The audit reports these as wording/scope issues, not failures of T4. The existence claim remains undecided.
